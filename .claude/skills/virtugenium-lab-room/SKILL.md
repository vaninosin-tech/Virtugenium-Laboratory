# Virtugenium Laboratory Room

Apply together with `virtugenium-3d-modeling` when Blender assets are involved.

## Source of truth

The room and furniture placement are procedurally generated by the game.

The existing procedural scene layout is approved and must remain unchanged unless the user explicitly requests a layout change.

Do not:

- change room width/length/height;
- move established walls;
- move existing furniture;
- rotate furniture;
- redesign interaction zones;
- move camera focus targets because a visual asset is inconvenient.

Add visual/architectural detail around the existing layout instead.

## Art direction

The room should feel like a bright modern university chemistry laboratory.

Avoid:

- prison/bunker atmosphere;
- dark industrial monochrome;
- concrete-block or prison-like tiled walls;
- sterile all-white hospital appearance;
- sci-fi neon styling.

Preferred palette:

- main walls: light gray-green around `#DDE1DE`;
- lower washable/protective wall zone, roughly 1.0–1.1 m high where appropriate: `#AEBDB8`;
- floor: seamless industrial epoxy around `#626B70`, medium gray rather than near-black;
- ceiling: near-white around `#F1F2EF`;
- furniture: light gray `#D0D4D2`;
- technical details: graphite `#3F484D`;
- work surfaces: around `#687377`.

Use these as art-direction anchors, not mandatory literal final values if lighting requires slight adjustment.

## Walls

Prefer smooth washable painted laboratory walls with subtle texture. Do not use large gray masonry/tile blocks as the dominant wall language.

A lower protective wall finish may be added without shifting the room boundary.

## Floor

Use a seamless or nearly seamless laboratory epoxy/resin look. Keep it moderately dark for contrast but not black.

## Ceiling and light

Use a clean modern technical ceiling with rectangular LED fixtures.

Target neutral working light around 4000–4500 K in the game/render setup.

Keep the room bright enough that dark furniture details remain readable.

## Window and windowsill

A window with a real windowsill is allowed and desired if it can be placed on an actually free wall section without changing existing furniture placement or gameplay zones.

Before adding it:

1. inspect the procedural wall and nearby furniture coordinates;
2. confirm the opening does not intersect furniture, doors, focus zones or existing geometry;
3. keep room dimensions unchanged;
4. implement the window as an architectural addition to the existing wall generation.

Do not move furniture merely to create a window.

## Supporting architectural detail

Use restrained functional details only where useful:

- baseboards/plinth line;
- outlets;
- cable channel where plausible;
- ventilation grilles;
- simple safety signage;
- ceiling vents;
- emergency/safety fixtures if they fit the scene.

Avoid filling every wall with props.

## Procedural implementation principle

When the game generates the room, separate:

- LOCKED layout constants: dimensions and existing placement;
- EDITABLE visual layer: materials, trim, window geometry, lights, vents, outlets and other architectural dressing.

Never silently modify locked layout constants during a visual pass.
