# Worker "perf": make the floc system fast without changing what it does

Cache `nodeRadius` per step.
2. Behaviour must stay the same within numerical noise. Record numbers from the CURRENT commit first, hard-code them with tolerances in a test and assert them after the change: scenario of `tests/night/wave3flocs/flocSystem.test.ts` (3 s pour, 14 s total at HIGH).
