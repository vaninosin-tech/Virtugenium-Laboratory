VIRTUGENIUM LABORATORY — КОНТЕКСТ ПО ОПЫТАМ
=============================================

Этот файл — справочный контекст (для Cursor/другого AI-инструмента) с полным
описанием всех лабораторных опытов игры: их сюжет, требуемые реактивы и
оборудование, этапы прохождения, итоговые уравнения реакций и баллы.

Источник данных (единственный source of truth в коде):
  src/data/content/experiments.ts  — объект LABORATORY_CONTENT (items + experiments)
  src/entities/laboratory/model/types.ts — типы Experiment / ExperimentStep / ChemicalEquation

Если меняется контент опытов — правь experiments.ts, а не этот файл; этот файл
нужно регенерировать/актуализировать вручную вслед за изменениями в коде.

ВАЖНО про вкладки планшета в игре ("Описание", "Этапы", "Теория", "Ошибки",
"Ответ"): только "Описание", "Этапы" и "Ответ" — это реально авторский контент
per-experiment (ниже). "Теория" — это НЕ текст по конкретному опыту, а общий
список всех реагентов проекта (имя/формула/описание) из items. "Ошибки" — это
не статический текст, а пустой живой лог ошибок игрока (errors из стора),
пока ничем не заполняется.

ОПЫТ 1: Медь и разбавленная азотная кислота
id: experiment-copper-nitric-acid
Максимум баллов: 10          Шагов: 4

ОПИСАНИЕ
В пробирку с гранулами меди приливают разбавленную азотную кислоту и слегка
нагревают. Выделяющийся бесцветный газ на воздухе буреет.

ТРЕБУЕТСЯ
- Медь (гранулы) — Cu, серо-розовые гранулы
- Азотная кислота (разбавленная) — HNO3, бесцветная прозрачная сильная кислота
- Пробирка
- Держатель пробирки
- Защитные очки
- Резиновые перчатки
- Халат

ЭТАПЫ
1. Надеть средства индивидуальной защиты
   Наденьте очки, перчатки и халат перед началом опыта.
   Баллы: +3 (СИЗ надеты перед началом опыта) / −3 (опыт начат без средств защиты)

2. Смешать вещества в правильном порядке
   Поместите гранулы меди в пробирку, закреплённую в держателе, и медленно
   прилейте азотную кислоту.
   Баллы: +2 (порядок смешивания соблюдён) / −1 (нарушен порядок смешивания)

3. Прогреть и нагреть пробирку
   Равномерно прогрейте пробирку над пламенем спиртовки, затем слегка
   нагрейте содержимое.
   Баллы: +2 (пробирка прогрета и нагрета правильно) / −2 (пробирка нагрета
   без предварительного прогрева)

4. Записать уравнения реакций
   Запишите уравнение реакции меди с азотной кислотой и уравнение окисления
   оксида азота(II) кислородом воздуха.
   Баллы: +3 (уравнения записаны верно) / −1 (уравнение записано неверно)

УРАВНЕНИЯ (ОТВЕТ)
  3Cu + 8HNO3 -> 3Cu(NO3)2 + 2NO + 4H2O
  2NO + O2 -> 2NO2

ОПЫТ 2: Нитрат серебра и хлорид натрия
id: experiment-silver-nitrate-sodium-chloride
Максимум баллов: 8          Шагов: 3

ОПИСАНИЕ
К раствору нитрата серебра приливают раствор хлорида натрия. Выпадает белый
творожистый осадок хлорида серебра.

ТРЕБУЕТСЯ
- Нитрат серебра — AgNO3, бесцветный раствор соли серебра
- Хлорид натрия — NaCl, бесцветный прозрачный раствор поваренной соли
- Пробирка
- Защитные очки
- Резиновые перчатки
- Халат

ЭТАПЫ
1. Надеть средства индивидуальной защиты
   Наденьте очки, перчатки и халат перед началом опыта.
   Баллы: +3 (СИЗ надеты перед началом опыта) / −3 (опыт начат без средств защиты)

2. Слить растворы
   Прилейте раствор хлорида натрия к раствору нитрата серебра.
   Баллы: +2 (растворы слиты правильно)

3. Записать уравнения реакции
   Запишите молекулярное, полное ионное и краткое ионное уравнение реакции.
   Баллы: +3 (уравнения записаны верно) / −1 (уравнение записано неверно)

УРАВНЕНИЯ (ОТВЕТ)
  Молекулярное:      NaCl + AgNO3 -> AgCl + NaNO3
  Краткое ионное:     Ag+ + Cl- -> AgCl

   Наденьте очки, перчатки и халат перед началом опыта.
   Баллы: +3 (СИЗ надеты перед началом опыта) / −3 (опыт начат без средств защиты)

2. Слить растворы
   Прилейте избыток раствора сульфата калия к раствору хлорида бария.

ОПЫТ 4: Серная кислота, сульфит натрия и перманганат калия
id: experiment-redox-permanganate-sulfite
Максимум баллов: 9          Шагов: 3

ОПИСАНИЕ
Окислительно-восстановительная реакция в кислой среде: перманганат калия
обесцвечивается сульфитом натрия в присутствии серной кислоты.

ТРЕБУЕТСЯ
- Серная кислота — H2SO4, бесцветная прозрачная сильная кислота
- Сульфит натрия — Na2SO3, бесцветный прозрачный раствор сульфита натрия
- Перманганат калия — KMnO4, тёмно-малиновый раствор
- Пробирка
- Защитные очки
- Резиновые перчатки
- Халат

ЭТАПЫ
1. Надеть средства индивидуальной защиты
   Наденьте очки, перчатки и халат перед началом опыта.
   Баллы: +3 (СИЗ надеты перед началом опыта) / −3 (опыт начат без средств защиты)

2. Слить реактивы
   Подкислите раствор сульфита натрия серной кислотой, затем прилейте раствор
   перманганата калия.
   Баллы: +2 (реактивы смешаны правильно)

3. Записать уравнение и электронный баланс
   Запишите уравнение реакции, составьте электронный баланс, укажите
   окислитель и восстановитель.
   Баллы: +4 (уравнение и баланс записаны верно) / −1 (уравнение записано
   неверно)

УРАВНЕНИЕ (ОТВЕТ)
  5Na2SO3 + 2KMnO4 + 3H2SO4 -> 5Na2SO4 + 2MnSO4 + K2SO4 + 3H2O

ПРИМЕЧАНИЕ ПО СХЕМЕ ДАННЫХ (для тех, кто правит experiments.ts)

Experiment {
  id, title, description,
  requiredItemIds: EntityId[],       // ссылки на items выше
  steps: ExperimentStep[],
  equations: ChemicalEquation[],
  maximumScore: number,
}

ExperimentStep {
  id, title, instruction,
  allowedActions: ("take-item" | "place-item" | "pour" | "mix" | "heat" |
                    "submit-equation" | ...)[],
  requirements: StepRequirement[],   // условие перехода к следующему шагу
  successScoreRules: ScoreRule[],    // { id, points, reason }
  errorScoreRules: ScoreRule[],
}

ChemicalEquation {
  id, molecular, completeIonic?, netIonic?,
}

Комментарий в самом experiments.ts: расчёт очков сейчас упрощён (одно правило
на шаг), а не полная многоблочная рубрика из ТЗ (например, опыт 1 в ТЗ
оценивается по пяти блокам на 34 балла). Полная схема начисления баллов
за действия ждёт реальной 3D-механики работы с реактивами (розлив,
нагрев, СИЗ, вытяжной шкаф) — сейчас вкладка "Эксперимент" в планшете это
только заглушка.
