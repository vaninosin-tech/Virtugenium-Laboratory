# Критически важное требование: локальное начало и пространственное распространение реакций

Источник — заказчик, 11.10. Дополняет `chemistry_four_experiments_corrected.md` и обязательно для всех
четырёх опытов.

**Ключевой принцип: точка попадания → локальное смешивание → местная химическая реакция → перенос
реагентов и продуктов → развитие реакции в новых областях.** Никакого мгновенного изменения всей
пробирки и никаких заранее заданных волн реакции.

## 1. Попадание реагента
1. Определить точку фактического попадания струи в существующую жидкость.
2. Увеличивать объём раствора одновременно с поступлением жидкости.
3. Добавлять вещества в локальную область 3D-поля у точки попадания.
4. Передавать жидкости импульс падающей струи.
5. Переносить поступившие вещества 3D-полем скорости.
6. Считать реакции локально там, где одновременно есть нужные реагенты.
Не распределять реагент мгновенно по всей пробирке.

## 2. Трёхмерное распространение
`concentration[reagent][x][y][z]` для каждого растворённого реагента: перенос течением, смешивание
соседних областей, локальная диффузия, импульс струи, конвекция при нагреве, движение пробирки.

## 3. Локальная реакция
В каждом активном участке: реагенты есть → локальное количество прореагировавшего, расход строго по
стехиометрии, продукты, локальный вид жидкости. Продукты переносятся по своей природе: растворённые —
жидкостью; осадок — жидкостью и седиментацией; газ — системой пузырьков. Никаких глобальных событий.

## 4. Опыты
- **Cu + разб. HNO₃** — только на смоченной поверхности меди; источники Cu²⁺ и NO — на активных
  участках металла; голубизна распространяется от меди с движением раствора.
- **AgNO₃ + NaCl** — AgCl локально в зонах смешения Ag⁺ и Cl⁻; взвесь переносится, часть агрегирует и
  оседает; в других областях реакция начинается только после прихода туда реагентов.
- **BaCl₂ + K₂SO₄** — BaSO₄ локально при встрече Ba²⁺ и SO₄²⁻; облака взвеси, затем оседание.
- **KMnO₄ + подкисленный Na₂SO₃** — MnO₄⁻ расходуется локально при SO₃²⁻ и H⁺; 2 : 5 : 6.

## 5. Скорость наливания
Медленно — компактные локальные реакционные области. Интенсивная струя — сильнее течения, реагенты
дальше от точки попадания, иная форма областей, больше зон контакта, сложнее объёмные структуры.
Не заменять ускорением глобальной анимации.

## 6. Нагрев
Меняет температурное поле, локальные скорости реакций (где предусмотрено), конвекцию, перенос, форму и
движение окрашенных областей. Не создаёт веществ без реакции.

## 7. Уровень жидкости
Объём растёт одновременно с попаданием реагента; при подъёме уровня расширяется область 3D-симуляции;
существующие поля и продукты сохраняются; состояние не сбрасывается при изменении уровня.

## 8. Критерий приёмки
При добавлении реагента в **разных местах** одной пробирки первоначальные реакционные области
образуются **в разных местах**; дальнейшее развитие определяется течениями, концентрациями и химией.
