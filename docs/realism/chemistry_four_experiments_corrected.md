# Claude → Codex: исправленная 3D-спецификация четырёх виртуальных опытов

**Контекст:** существующий лабораторный симулятор на React + Three.js. Это ТЗ только для цифровой визуализации: не описывает проведение реальных опытов, концентрации растворов, дозировки или работу с токсичными веществами. При наличии доступа к репозиторию Claude сначала обязан прочитать `docs/codex/cu-hno3-plan.md`, текущие задачи 45–51, код пробирки, жидкостей, нагревателя, реакционного контроллера и системы перетаскивания. Цель — исправить существующую реализацию, а не заменить её отдельным демо.

## 0. ФИКСИРОВАННЫЕ реакции: никаких альтернатив

**Опыт 1 — разбавленная HNO₃:**

- `3Cu + 8HNO₃(разб.) → 3Cu(NO₃)₂ + 2NO↑ + 4H₂O`
- `3Cu + 8H⁺ + 2NO₃⁻ → 3Cu²⁺ + 2NO↑ + 4H₂O`
- **Вторая, отдельная реакция, только при контакте с O₂:** `2NO + O₂ → 2NO₂`. Выделяющийся из раствора NO бесцветен, NO₂ бурый. Не подменять опыт вариантом с концентрированной кислотой и первичным выделением бурого газа.

**Опыт 2:**

- `AgNO₃ + NaCl → AgCl↓ + NaNO₃`
- `Ag⁺ + Cl⁻ → AgCl↓`

**Опыт 3:**

- `BaCl₂ + K₂SO₄ → BaSO₄↓ + 2KCl`
- `Ba²⁺ + SO₄²⁻ → BaSO₄↓`

**Опыт 4 — кислая среда:**

- `5Na₂SO₃ + 2KMnO₄ + 3H₂SO₄ → 5Na₂SO₄ + 2MnSO₄ + K₂SO₄ + 3H₂O`
- `5SO₃²⁻ + 2MnO₄⁻ + 6H⁺ → 5SO₄²⁻ + 2Mn²⁺ + 3H₂O`
- Электронный баланс: `Mn(+VII) + 5e⁻ → Mn(+II)` (×2); `S(+IV) → S(+VI) + 2e⁻` (×5).
- Возможная **отдельная** побочная реакция при подкислении сульфита: `Na₂SO₃ + H₂SO₄ → Na₂SO₄ + SO₂↑ + H₂O`. Не смешивать её газовыделение с основной реакцией. По умолчанию в короткой учебной визуализации основного опыта газовая подсистема выключена: видимых пузырьков от основного редокс-процесса нет. Возможность SO₂ зависит от отдельно моделируемых условий, не является обязательным визуальным результатом.

**Все уравнения предоставлены пользователем и являются единственными целевыми схемами.** Спецификация должна сохранять их без добавления другой обязательной химии.

## 1. Что исправить концептуально

В одном проекте представлены четыре **разные физические формы**:

| Опыт | Что наблюдает пользователь | Математический объект | Оптическая модель |
|---|---|---|---|
| Cu | Прозрачные голубые трёхмерные струи + бесцветные пузырьки NO; бурый газ лишь там, где NO встречает O₂ | Объёмное поле растворённого Cu²⁺ + отдельные газовые фазы | Селективное поглощение света раствором, отдельно полупрозрачный газ |
| AgCl | Белая молочная взвесь → рыхлые творожистые хлопья → объёмный рыхлый осадок | Поле мелкой взвеси + массив индивидуальных агрегатов + донная масса | Светорассеяние частиц, неоднородная плотность хлопьев |
| BaSO₄ | Мелкая белая взвесь, облака из зоны смешения → постепенное осветление сверху вниз → сравнительно плотный тонкий слой | Поле мелкой взвеси с распределением по размерам + донная масса | Сильное интегральное светорассеяние; не рисовать хлопья AgCl |
| KMnO₄ | Фиолетово-малиновые языки → локальное обесцвечивание при контакте с сульфитом → прозрачный раствор либо слабая остаточная розовая окраска | Два/три адвектируемых поля реагентов и локальная химическая реакция | Поглощение цвета растворённым MnO₄⁻; никаких твёрдых частиц |

НЕЛЬЗЯ: однотипные белые шарики для осадков; спрайты голубого дыма вместо Cu²⁺; глобальное `lerp(color)`; исчезновение цвета MnO₄⁻ по времени жизни частицы; одинаковые законы оседания AgCl и BaSO₄.

## 2. Общая 3D-архитектура: Three.js + React

### 2.1. Разделение данных и рендера

- `ReactionState` хранит учётные количества вещества в условных игровых единицах, отдельно от видимой насыщенности.
- `LiquidMask(x,y,z)` хранит фактический жидкий объём, границы стекла, мениск с учётом ориентации и положения пробирки.
- `SpeciesField[chemicalId](x,y,z)` хранит объёмные концентрации **растворённых** реагентов/продуктов.
- `SuspensionField` хранит массовую плотность **мелких твёрдых частиц**, а не яркость белого цвета.
- `FlocAggregate[]` хранит крупные агрегаты AgCl (центр масс, масса, неправильная форма, пористость, скорость).
- `SedimentField(x,z)` хранит накопленную на дне массу и объём/пористость.
- `VelocityField(x,y,z)` переносит растворённые вещества и увлекает частицы; создаётся из нескольких физических вкладов.
- `TemperatureField` учитывает локальный нагрев, тепловую инерцию и остывание, когда виртуальная пробирка убрана от горелки.
- `GasState` раздельно учитывает **NO** и **NO₂**; кислородная доступность газовой фазы — отдельный игровой параметр.

### 2.2. Цикл обновления

1. Получить актуальный контакт виртуальных веществ и объём добавленного раствора.
2. Обновить занятость жидкостью и поле движения, включая поворот/ускорение пробирки, пузырьки и температурные градиенты.
3. Перенести поля реагентов потоками (`advection`) и ограниченной диффузией, с корректной обработкой стенок.
4. Вычислить локальные реакции **по стехиометрическим коэффициентам**, а не по таймеру.
5. Списать реагенты, записать продукты в те же клетки жидкости (либо рядом с медной поверхностью), сформировать взвесь/газ.
6. Для AgCl: часть мелкой массы может переходить в рыхлые агрегаты; для BaSO₄: распределение размеров преимущественно мелкое. Затем осаждение, обратный подъём при встряхивании и перераспределение донной массы.
7. Передать поля в GPU и отрисовать объём с правильной глубиной, прозрачным стеклом и находящимися внутри непрозрачными предметами.

Рекомендуемые стартовые параметры производительности — маленькая 3D-текстура `32×64×32`, фиксированная частота модели около 20–30 Гц и отдельная интерполяция кадров. Это **только технические пресеты**; оптимальное качество выбрать по профилированию. GPU-набор средств зависит от существующего рендерера: `THREE.Data3DTexture` в WebGL2/трёхмерный ray marching либо сопоставимая объёмная реализация. Система должна работать со свободной камерой вокруг пробирки: шлейфы не могут быть плоскими billboard-объектами.

### 2.3. Локальная стехиометрия (без рецептов и концентраций реальных растворов)

Модель использует малую нормированную степень протекания реакции `ξ ≥ 0`. Перед каждым шагом `ξ` ограничивается доступными количествами веществ в соответствующей области. Для каждой реакции расход и образование строго пропорциональны коэффициентам из раздела 0.

- **R1:** на `ξ`: `Cu -= 3ξ`, `HNO₃(эквивалент) -= 8ξ`, `Cu(II) += 3ξ`, `NO += 2ξ`. Отдельно для воздуха `NO -= 2η`, `O₂ -= η`, `NO₂ += 2η`. Первичная газовая визуализация бесцветная.
- **R2:** `Ag⁺ -= ξ`, `Cl⁻ -= ξ`, `AgCl(s) += ξ` в области смешения двух полей.
- **R3:** `Ba²⁺ -= ξ`, `SO₄²⁻ -= ξ`, `BaSO₄(s) += ξ` в области смешения.
- **R4:** `SO₃²⁻ -= 5ξ`, `MnO₄⁻ -= 2ξ`, `H⁺ -= 6ξ`, `SO₄²⁻ += 5ξ`, `Mn²⁺ += 2ξ`. На цвет влияет **только оставшийся MnO₄⁻**. Если он полностью израсходован, голубого/белого осадка нет и цвет пропадает; при его избытке остаётся розово-лиловый оттенок. Побочная реакция SO₂ — отдельный путь с отдельным балансом и визуализацией, выключенная по умолчанию.

Проверить неотрицательность полей, локальность взаимодействий, общий учёт массы/заряда и ограничение переноса через стенки. Реакции не должны продолжаться без контакта реагирующих полей. При переносе, нагреве и встряхивании количество вещества не меняется самопроизвольно.

## 3. Опыт 1 — 3Cu + 8HNO₃(разб.) → 3Cu(NO₃)₂ + 2NO↑ + 4H₂O

### Пошаговая видимая картина

1. В пробирке **прозрачный** раствор и металлическая медь. Никакого исходного бурого газа и обязательной зелени.
2. На смоченной поверхности меди в разных микрозонах постепенно зарождаются **бесцветные** пузырьки NO. Они мелкие, не возникают синхронно, прикрепляются к металлу, растут, отрываются и поднимаются против мировой гравитации.
3. Почти одновременно вокруг активных участков меди видны первые очень слабые **светло-голубые** пятна раствора Cu(II). Они неровные, разной плотности, появляются только около меди.
4. Пятна вытягиваются в **прозрачные трёхмерные голубые струи**; часть движется вверх вместе с пузырьковыми потоками, часть — вбок с локальными перемешиваниями. Это настоящая концентрация внутри жидкости, а не синяя геометрия.
5. Когда пробирку греют виртуальной горелкой, **локальная температура** меняется постепенно. Конвекция перестраивает форму струй; нагрев также может изменить модельную реакционную скорость при сохранённом контакте. После прекращения нагрева потоки не исчезают мгновенно.
6. За счёт накопления Cu²⁺ раствор становится постепенно более равномерно голубым и остаётся прозрачным. Уже образовавшийся цвет нельзя удалять по lifetime.
7. Только в газовом пространстве, где есть контакт NO с O₂, допускается **бурый NO₂**. Нельзя делать бурые пузырьки, зарождающиеся на меди: для заданной разбавленной HNO₃ это неверный базовый результат.

### Важное о пузырьках

Система вправе использовать художественные диапазоны частоты частиц, но **не утверждать**, что фиксированное количество пузырьков/секунду следует из уравнения. Количество видимых мешей на экране — производительная выборка общего виртуального потока газа. Зарождение зависит от площади смоченной поверхности, текущего источника NO и стохастических мест эмиссии; движение — от радиуса, гравитации и локального течения. Не прорисовывать коричневую массу вместо пузырька NO.

## 4. Опыт 2 — AgNO₃ + NaCl → AgCl↓ + NaNO₃

### Пошаговая видимая картина

1. Два исходных прозрачных раствора остаются прозрачными каждый сам по себе.
2. Там, где объёмная входящая струя NaCl **локально встречает** Ag⁺, быстро образуется белая мелкая дисперсия AgCl. Не создавать белое пятно заранее во всём объёме.
3. Первые белые области похожи на полупрозрачную **молочную взвесь**, изгибаются вместе со струёй и локальными вихрями.
4. Часть образовавшейся массы переходит в **отдельные творожистые хлопья**, размеры и формы разные: изогнутые, неровные, с пустотами, не гладкие шары и не одинаковые снежки. Форма должна работать с любой стороны камеры.
5. Мелкая взвесь и крупные хлопья существуют одновременно. При объединении хлопьев корректно суммируются **их массы**, а не просто увеличивается белизна.
6. Хлопья оседают с разными скоростями, зависящими от размера, плотности и сопротивления жидкости. На дне формируется более **рыхлый, неровный** слой, чем у BaSO₄.
7. При наклоне/встряхивании осадок может сдвигаться и частично возвращаться во взвесь; жидкость снова мутнеет. После успокоения частицы оседают снова.

**Коррекция:** нагрев **не гарантирует** ускорения слипания AgCl. Если нужен эффект температуры, он должен идти через изменение вязкости/течения и отдельно калибруемую вероятность агрегации. Не зашивать «чем горячее, тем крупнее хлопья» как обязательный закон.

## 5. Опыт 3 — BaCl₂ + K₂SO₄ → BaSO₄↓ + 2KCl

### Пошаговая видимая картина

1. Исходные растворы прозрачны.
2. В зоне пересечения входящей струи с полем Ba²⁺ быстро появляется **тонкая белая муть**.
3. Микрокристаллическая взвесь образует размытые облака, как беловатый туман в воде, но это **частицы в жидкости**, а не объёмный газ.
4. При достаточной концентрации частиц оптическая толщина возрастает, и большая часть объёма выглядит молочно-белой. Нельзя автоматически назначать «вся пробирка белая через ровно 3 секунды»; если нужен такой монтаж — это только демонстрационный preset.
5. Частицы постепенно оседают, при этом прозрачные области появляются преимущественно сверху, по мере потери взвеси из верхнего слоя. Светление должно следовать за `SuspensionField`, а не за глобальным таймером.
6. На дне остаётся **относительно плотный, мелкозернистый, более тонкий** слой. Это стилистический контраст с рыхлой массой AgCl при сопоставимых условиях, но не универсальная химическая гарантия отсутствия агрегатов.
7. Встряхивание поднимает часть донной массы, снова формирует белую муть, затем та повторно оседает.

**Коррекция:** фраза «частицы никогда не слипаются» неверна как абсолютное утверждение. Для *этого* визуального пресета крупные рыхлые хлопья отключить либо свести к минимуму — но хранить модель распределения размеров, не запрет агрегации как химическое правило.

## 6. Опыт 4 — 5Na₂SO₃ + 2KMnO₄ + 3H₂SO₄ → ...

### Пошаговая видимая картина

1. Подкисленный сульфит в рамках основной реакции выглядит **прозрачным**. Отдельные KMnO₄-потоки фиолетово-малиновые.
2. Поступающая виртуальная струя несёт **растворённый MnO₄⁻**. Вся пробирка не окрашивается одномоментно: входящий поток создаёт реальные **3D-языки** разной насыщенности.
3. Поле сульфита уже присутствует в растворе. На поверхности соприкосновения струй происходит локальная химическая реакция. На **краях фиолетовых языков** цвет ослабевает, если там ещё есть SO₃²⁻ и H⁺. Внутренняя часть струи может некоторое время оставаться интенсивнее окрашенной.
4. При перемешивании увеличивается пространственный контакт реагентов, языки быстрее расходуются. Но скорость цвета определяется **совместно** переносом и локальной реакцией, а не одним движением воды или фиксированным таймером.
5. Для достаточного запаса SO₃²⁻ и H⁺ фиолетовые области постепенно полностью исчезают, жидкость становится практически прозрачной. Не показывать обязательные хлопья, мутность или коричневый осадок: в этом кислым сценарии продукт Mn²⁺ почти бесцветен.
6. Если MnO₄⁻ в виртуальном балансе в избытке, после расходования восстановителя цвет остаётся — светло-розовый при малом количестве или более фиолетовый при большом.
7. Отдельный газ SO₂ может быть предусмотрен *только* как опциональная побочная ветвь и при наличии соответствующей модели. По умолчанию отключён: не выдавать за газ основной реакции.

**Коррекция:** утверждение «фиолетовые языки тяжелее воды и обязаны опускаться» нельзя зашивать. Их направление задаётся относительной плотностью конкретных виртуальных растворов, импульсом добавления, ориентацией пробирки и течением. Вертикальный ход возможен, но **не универсален**. `3 секунды` — допустимый художественный эталон для короткой анимации, а не закон реакции.

## 7. Нагрев и движение пробирки — для всех четырёх

- Нагрев — локальный и инерционный; преобразовывать внешнее тепло в температурное поле, затем в конвективное движение. Удаление от горелки означает постепенное охлаждение.
- Нельзя одинаково масштабировать эффекты всех четырёх опытов параметром `temperatureMultiplier`: разные химические процессы и разные частицы.
- Cu: главное зрелище — изменение трёхмерных голубых струй. Допустимо изменение интенсивности реакции и пузырьков согласно выбранной модели.
- AgCl: нагрев прежде всего влияет на движение/оседание и только опционально на агрегацию.
- BaSO₄: нагрев меняет движение взвеси; не должен автоматически превращать её в хлопья AgCl.
- KMnO₄: реагенты остаются растворёнными, раздельно моделировать перенос и расход. Нагрев не создаёт фиолетовый цвет сам по себе.
- При наклоне пересчитывать гравитацию в локальной системе. При встряхивании — скорости и временное поднятие части осадка. Удерживание, перетаскивание, штатив/лапка, горелка и поднос должны работать как раньше. Не перезапускать 3D-поле при перемещении.

## 8. Рендеринг объёма

- Для Cu²⁺ и MnO₄⁻: плавное **селективное поглощение** света, например аппроксимация Beer–Lambert по локальной концентрации. У раствора отсутствует свечение (`emissive=0`) и не должно появляться «дымовых частиц».
- Для AgCl и BaSO₄: светорассеяние взвеси; молочность зависит от оптической толщины частиц вдоль луча. Белое вещество **находится внутри** жидкости, не на стекле. AgCl-агрегаты рендерить объёмными неправильными формами/изоповерхностями/группами лобов, не гладкими сферами.
- Качество 3D должно сохраняться при повороте камеры на 360°; невидимые грани, артефакты сортировки прозрачности и исчезновение меди недопустимы.
- Газ NO²⁻ не существует: не путать **NO(g)**, **NO₂(g)**, `NO₃⁻` и `Cu²⁺`. Газовые объёмы — отдельная фаза **выше мениска** или вне открытой пробирки при наличии воздуха.

## 9. Обязательные приёмочные тесты

1. **Cu без O₂ в газовой модели:** прозрачные пузырьки NO, голубой Cu²⁺ в жидкости, **никакого бурого NO₂**.
2. **Cu с O₂ в газовой области:** бурый оттенок развивается **после появления NO и контакта с O₂**, только в газовой фазе. Начальный жидкий объём прозрачный.
3. **Cu нагрев → убрать нагрев → повторить:** голубая концентрация сохраняется, конвекция плавно ускоряется и затухает; добавочный Cu²⁺ возникает только при реакции.
4. **AgCl:** морфология рыхлых хлопьев, одновременно мелкая взвесь, пористый осадок; консервация массы `fine + floc + sediment`.
5. **BaSO₄:** белое облако из зоны смешения, оседание сверху вниз, донный мелкозернистый слой; повторная мутность при встряхивании.
6. **KMnO₄ с запасом сульфита:** локально исчезают цветовые границы, без хлопьев и бурых частиц, к завершению нет MnO₄⁻.
7. **KMnO₄ в избытке:** сохраняется исходная окрашенная форма в виде розового/фиолетового раствора, пока осталось поле MnO₄⁻.
8. **Стехиометрия R4:** на каждый симуляционный шаг отношение расхода `MnO₄⁻ : SO₃²⁻ : H⁺ = 2 : 5 : 6`; кислый сценарий не даёт обязательного MnO₂.
9. **Физика:** пробирка наклонена, поднята со стола, в лапке, на подносе, у источника тепла: поля не сбрасываются; пузырьки не вылетают сквозь стекло; осадок не исчезает.
10. **Рендер:** фронт/сбоку/сверху/круговой обзор; стекло/жидкость/медь/объёмный материал имеют корректный порядок глубины.
11. **Производительность:** 30/60/144 FPS дают сопоставимый симуляционный результат; никакого рождения пузырьков «по одному за кадр».
12. **Автотесты:** сохраняется баланс вещества, нет отрицательных концентраций/NaN, масса не теряется при переносе внутри закрытого жидкого объёма, нагрев без реагентов не создаёт продуктов.

## 10. Порядок задач Claude → Codex

1. **45–48:** общий объёмный 3D-слой, концентрации, физический перенос, корректный Cu/NO/NO₂, нагрев и визуальные струи; тесты.
2. **49:** опыт 4 с локальными полями MnO₄⁻, SO₃²⁻, H⁺, точной стехиометрией 2:5:6 и исчезновением окраски только вследствие реакции.
3. **50:** опыт 3 с объёмной взвесью BaSO₄, моделированием оседания и осветлением сверху вниз.
4. **51:** опыт 2 с отдельной массой мелкой взвеси, рыхлых AgCl-хлопьев и донного осадка.

После каждой задачи: покажи скриншоты/короткий захват нескольких стадий с нескольких ракурсов, сравни с видеореференсом **только если реально просмотрел его**, выполни typecheck/lint/tests, перечисли изменённые файлы. До коммита доложи о конфликтующих ограничениях. Не утверждай, что это точная молекулярная CFD-модель: это производительная 3D-аппроксимация для учебного симулятора.

## Критическое требование от пользователя

**В опыте 1 особенно важно видеть плавное рождение голубизны на меди и её превращение в голубые 3D-потоки.** При нагревании потоки меняют скорость и направление, после остывания продолжают затухать. При этом в данной реакции газ **сначала NO — бесцветный**; бурый NO₂ — отдельное следствие контакта NO с воздухом. В опыте 4 раствор именно обесцвечивается локально, а не «теряет фиолетовые частицы по таймеру». Осадки AgCl и BaSO₄ должны иметь **разную морфологию**, несмотря на одинаковый белый цвет.
