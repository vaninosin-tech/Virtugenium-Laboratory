# VL-012 — состояние приложения и лабораторной сессии

## Реализованное состояние

Zustand-store хранит:

- режим приложения;
- текущий экран;
- ракурс камеры;
- состояние и раздел планшета;
- выбранный опыт и текущий этап;
- инвентарь и корзину;
- завершённые этапы и опыты;
- события начисления баллов;
- ошибки лабораторной сессии;
- время начала и завершения попытки;
- цвет жидкости в тестовой 3D-сцене.

## Реализованные действия

- изменение режима, экрана и ракурса;
- открытие и закрытие планшета;
- добавление и удаление предметов;
- выбор опыта;
- переход между этапами;
- завершение этапов и опытов;
- добавление баллов и ошибок;
- завершение сессии;
- полный сброс попытки.

## Автоматические проверки

- `npm test` — успешно пройдено 11 unit-тестов;
- `npm run typecheck` — успешно;
- `npm run lint` — успешно;
- `npm run check:cycles` — циклических импортов нет;
- `npm run build` — production-сборка успешна.

## Ручная проверка

Приложение запущено через `npm run tauri -- dev`. Явных нарушений работы главного меню и существующей 3D-сцены не обнаружено.

## Примечание

Vite выводит неблокирующее предупреждение о размере JavaScript-пакета из-за Three.js.
