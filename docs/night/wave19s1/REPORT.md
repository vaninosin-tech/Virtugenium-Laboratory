# Wave 19 S1: AgCl aggregation sensitivity

## Decision

**Outcome 2.** None of the 16 bounded radius and attachment assumptions produces a materially large, individually settling aggregate by 22 s. Primary coagulation can be nearly complete while the mass remains mostly in submicrometre sections. The visible cotton effect therefore has to rely more on transported, concentrated suspension regions if the present population model is retained. The principal limits are the 22 s residence time, the small Brownian and resolved-shear collision kernels after primary depletion, and the fixed-pivot section scheme's slow particle-number loss. A vanishing numerical tail reaches the last 1.76 mm pivot in every run; this is **not** a millimetre floc. No node promotes in any run.

This is a headless simulation and CPU optical-reference investigation. No browser visual result is claimed. No collision, flow, reagent, geometry, fine-production or optical parameter was tuned to make a visual pass. The no-aggregation baseline remains selectable with `__silverAgg = 0`.

## Assumptions and exact replay

The grid is radius `0.02, 0.05, 0.10, 0.20` µm crossed with sticking scales `0.05, 0.2, 0.5, 1.0`. Both are **model assumptions**, not measured AgCl constants. The radius hook accepts only 0.02 to 0.2 µm. The scale hook is clamped to [0, 1]. It multiplies the existing local electrolyte-dependent probability, whose factors are `0.05 + 0.9 E/(E+0.005)` and `0.8 + 0.2 C/(C+0.001)`, so effective sticking remains between 0 and 0.95. The LOW real-pour schedule and transport are copied from the wave 18 replay: 50 ms steps, 1 mL receiving liquid, delivery of 1 mL over 1.25 s, physical liquid-level updates, actual inlet placement, `__silverJetModel` and `__silverSubgrid` off. The selected point also runs HIGH. [Each point's CSV](summary.csv) contains 3, 6, 9, 14 and 22 s plus 1, 2, 4.5, 12, 17 and 20 s. Each CSV includes extent, all solid reservoirs, 13 section masses and particle counts, 13 incoming growth rates and slip speeds, settling, erosion, fragmentation, threshold radii, spatial concentration and optical metrics. [Threshold crossings](crossings.json) records the first sampled crossing through 3, 10, 30, 100 and 1000 µm for the mass-weighted radius and the largest class holding at least 0.001 or 0.01 unit. Missing keys mean not reached by 22 s. `maxRadiusUm` alone includes arbitrarily tiny tails and is not evidence of an actual floc.

## Units and rate audit, performed before interpreting the grid

One game unit is 0.1 mmol AgCl. At 143.32 g/mol it is 14.332 mg or `1.4332e-5 kg`; at 5560 kg/m³ its compact volume is `V_u = 2.57770e-9 m³/unit`. Dispersed in 2 mL (`2e-6 m³`), one full unit has solid volume fraction `phi = V_u/V_l = 1.28885e-3` (dimensionless). For primary radius `a` in metres, `v_p = 4 pi a³/3` m³/particle and `n = phi/v_p` particles/m³. The code's local form is `n = fine[unit] V_u[m³/unit] / (v_p[m³/particle] V_cell[m³])`; therefore it uses particle **number** concentration, not normalized mass as a stand-in for number.

The equal-sphere Brownian kernel in the code is `K_B = 8 k_B T/(3 mu) = 1.07715e-17 m³/s` at 293.15 K and `mu = 1.002e-3 Pa s`. The alternative `4 k_B T/(3 mu)` convention is half this value; it must not be substituted without accounting for pair counting. For a single identical population, collision events per volume are `r = alpha K_B n²/2` particles/m³/s and total particle number follows `dN/dt = -alpha K_B N²/2`; hence `t_1/2 = 2/(alpha K_B n_0)`. Two *fine primaries* disappear per event, so the fine-only source term has `dn_f/dt = -alpha K_B n_f²`, consistent with the code's exponential fine transfer to section 0. The exponential differs from a forward-Euler update at finite dt but has the same differential rate. The section kernel is `2 kT/(3 mu) (r_i+r_j)(1/r_i+1/r_j)`, which reduces exactly to `8 kT/(3 mu)` for equal radii. The section event source includes the required `1/2` for `i=j`.

The implemented shear kernel is `G(r_i+r_j)³/3` m³/s, including fine-primary `G(2a)³/3`. The usual rectilinear orthokinetic convention `4G(r_i+r_j)³/3` is four times larger. This is a model coefficient difference, **not** a units error. The kernel is multiplied by bounded local `alpha` before rate integration. A 0.20 µm primary at full-unit mean concentration has `n=3.8461e16 m⁻³`; the `alpha=1` Brownian half-life is 4.828 s. The 0.10, 0.05 and 0.02 µm values are 0.6035, 0.07543 and 0.004828 s respectively. Actual local sticking is below 1, so these are lower bounds for each radius at full-unit concentration. At 22 s, use `t_half = t_half,full / (scale * mean fine unit)` for a mean-concentration estimate, again a lower bound because the electrolyte factor is below 1. The estimate for 0.05 µm/full scale is 12.16 s on LOW and 7.94 s on HIGH; local heterogeneous rates differ. The same calculation for every point is reproducible from the CSV fine column.

The homogeneous-box test uses one wet cell at `n_0=1e17 m⁻³`, `alpha=1`, zero shear, 50 ms steps and 5 s. The analytic constant-kernel result is `N_0/(1+K_B n_0 t/2)`; the section model retains **2.0283 times** that predicted total particle number. This fails an 8% physical agreement tolerance. The initial step represents only about 0.234 of the analytic particle-number loss. A dimer with mass `2 m0` is split between pivots `m0` and `m1`; that split represents a net loss of only `2 m0/m1 ≈ 0.232` particle per actual collision, before secondary within-step collisions. The mass-conserving fixed-pivot split therefore does not preserve the event's particle-number loss. Its products also sample size-dependent Brownian kernels rather than a strictly constant kernel; the current API cannot independently force a constant kernel. It biases large-size growth downward. `sectionalPopulation.ts` is S2-owned and its collision physics is frozen in this wave; no correction was made. This discretisation failure limits the physical inference from a lack of large classes, although the actual code's output is established. A future integration should redesign the pivot representation and validate both mass and number evolution against analytic box solutions before recalibrating any physical coefficient.

The finer radius and stronger sticking accelerate **fine-to-section-0** transfer. They do not accelerate subsequent section-to-section growth enough to create a material 10 µm class, much less a node. At 0.05 µm/full scale, LOW at 3, 6, 9, 14 and 22 s has `(fine, sections)` of `(.036,.439)`, `(.034,.728)`, `(.026,.854)`, `(.016,.934)` and `(.006,.953)`. Its mean section radius grows from .344 to .897 µm in the same interval. The 0.001-unit radius first reaches 3 µm at 20 s LOW and 17 s HIGH; the 0.01-unit radius reaches 3 µm only at 20 s HIGH. All other 10, 30, 100 and 1000 µm thresholds remain unachieved at material mass. There is no promotion because the local cell must hold one characteristic particle mass at a radius at least one quarter of grid spacing. Tiny high-pivot numerical tails cannot satisfy that criterion.

The first section pivot stays at 0.32 µm for every radius. Thus a primary collision at 0.02 µm is immediately assigned to a section whose characteristic radius is sixteen times the primary radius, skipping actual dimer and intermediate sizes. Because the compact section characteristic mass formula cancels its `primaryRadius` factors, the section masses and pivots are nearly radius-independent once the fine transfer has happened. This is a second numerical limitation on the small-radius sensitivity, separate from the fixed-pivot particle-number error. It can overstate early represented size while still understating subsequent number depletion.

Fine-to-section, class incoming-growth, section-to-sediment and node transfer rates are in unit/s in every CSV. Section particle counts are `class mass / characteristic particle mass`; class slip is m/s. The instantaneous fine-to-section rate measures primary loss, while the per-class incoming rates count transfer throughput and do not equal net class growth. Sediment receives only actual section mass flux; node settling, erosion and fragmentation are zero because there are no nodes. The maximal per-step conservation error across all LOW and selected HIGH runs is below `4.7e-14`, well below `1e-12`. The no-aggregation baseline has 0.99044 formed unit at 22 s, all fine, and zero sections and sediment.

## Unresolved structure and CPU optics

The unresolved density is exactly `sum(section mass per cell) * activeCount`, matching aggregate texture R. For each point and time the CSV gives wet-cell concentration p05/p50/p95/p99, coefficient of variation, x-gradient mean and maximum per mm, and 6-connected regions above 10% and 50% of positive p95. Region records include count, largest volume in mm³, surface/volume in mm⁻¹, aspect, bounding box in mm and radius of gyration in mm. Optical-depth fractions use a local diameter approximation `tau = 2(8*c_fine + 17*c_aggregate)` with the shader fine `kappa=8` and the unchanged CPU aggregate reference `kappa=17`; fractions above .05, .2 and 1 are recorded. This is an optical-density estimate across a tube diameter, not a rendered ray integral.

For the selected 0.05 µm/full-scale LOW run, p95 unresolved density rises to about 1.93 at 22 s while CV rises to 4.82. At 22 s, 88% of wet voxels exceed estimated diameter optical depth 1. The 50%-p95 region is one connected region with a roughly `9.33 x 2.90 x 9.33 mm` box. At 3 s its box is `9.33 x 8.70 x 10.50 mm`; the vertical narrowing and increasing CV show transport and settling of a concentrated cloud. HIGH gives CV 7.45 and 14 separate 50%-p95 regions at 22 s, so this geometry is grid-sensitive. These are **B**, mesoscopic cloud regions consisting of many **A**, microscopic aggregates. The baseline has no unresolved aggregate population and thus no A or B by this definition.

The 90 `.ppm` files are CPU-reference aggregate-only slices at 3, 6, 9, 14 and 22 s for all points and baseline. Their CSV luminance fields give image p95, p50, difference, and the count of 4-connected bright regions above image p90 when p90 exceeds .05. They are numerical reference renders, not browser captures. The baseline is black in this aggregate-only mode. For the selected LOW point, p95 saturates at 1, p50 is 0 because the exterior is black, and one bright region appears at each sampled time. These image-wide statistics cannot distinguish dense cores inside the tube; the saturation itself is an optical limitation of the present response. Classification **C**, individually settling visible flocs, is absent. Classification **D**, connected aggregate-only white cloud appearance, is present as a broad bright region; the measured cloud concentration and shape support broad lobes and clearer spaces, but neither these saturated images nor zero nodes establish hanging connected millimetre cotton strands. The scene appearance still needs the coordinator's real-game comparison.

## Selected configuration and integration

Use radius **0.05 µm** and sticking scale **1.0**. This is a plausible tens-of-nanometres primary assumption and uses the existing bounded high-electrolyte efficiency without claiming that its exact value is measured for this AgCl experiment. The choice was made for physical plausibility, not for maximum size; 0.02 µm gives slightly faster transfer but the same lack of large flocs. Coordinator INIT: `globalThis.__silverAgg=1; globalThis.__silverPrimaryRadiusUm=0.05; globalThis.__silverStickingScale=1; globalThis.__silverJetModel=0; globalThis.__silverSubgrid=0;`. The selected deterministic [wave19 state dumps](../wave16shared/) are at 1, 2, 3, 4.5, 6, 9, 12, 14, 17, 20 and 22 s. The last complete grid run refreshed them.

The needed next step is to validate or replace the fixed-pivot number evolution with a physically tested sectional scheme, then compare transport-generated cloud regions in the real game. This is an integration request to S2/coordinator; no collision-physics or renderer edit was made in an unowned file.
