# Задача 64 (исправленная): артефакт шейдера на дне баночек с реагентами

Касается именно БАНОЧЕК С РЕАГЕНТАМИ, не пробирок. Найти первопричину и исправить дно всех таких баночек.

1. Диагностика: геометрия баночек, внутренний объём реагента, стекло и дно, материалы/шейдеры содержимого,
   прозрачность и порядок отрисовки, отсечение содержимого границами ёмкости. Не считать причину только шейдером.
2. Геометрия дна: жидкость не пересекает стеклянное дно; нет обрезки слишком высоко, неправильной плоскости, щелей,
   инвертированных нормалей, конфликта внутренней и внешней геометрии. Дно цельное с любого ракурса.
3. Шейдер: локальные координаты, маска объёма, толщина слоя, переход стенка-дно, depthTest/depthWrite, сортировка,
   ошибки GLSL. Недопустимы чёрные/белые пятна, клинья, мерцание, резкие обрывы цвета, содержимое вне банки.
4. Проверить все типы банок: полная, частичная, малое количество, пустая, разные цвета, наклон и перемещение.
   Если шейдер общий, чинить общий компонент, без костылей для каждого реагента.
5. Совместимость: уровень содержимого, количество реагента не меняется, налив продолжает работать, положение
   жидкости относительно банки, крышки, захват, перетаскивание, hover-призраки.
6. Отладка по шагам: только геометрия; непрозрачный материал содержимого; текущий шейдер; со стеклом; вращение камеры.
   Дать сравнение до/после с одинаковыми ракурсами.
7. Приёмка: артефакт устранён, дно цельное со всех сторон, нет пересечений со стеклом, нет резких пятен, разные
   уровни корректны, налив и перемещение целы, пробирки не затронуты без необходимости.
Не маскировать дополнительным мешем или накладкой; исправить первопричину.

## Уточнение заказчика 13.10 (вечер): артефакты именно ПРИ HOVER на дне банки
Артефакт на дне баночки с реагентом виден **при наведении (hover)**, когда у банки включается подсветка/контур/ободок. Проверить и починить
первопричину в hover-слое для банок реагентов: `ui/ReagentHoverRim.tsx`, `ui/HoverOutline.tsx`, `ui/NormalHoverOutline*`
(контур по нормалям, Fresnel-ободок, inverted hull), их работу у дна (резкий излом нормалей на донном радиусе, depth/порядок прозрачных
слоёв, пересечение контура с содержимым и стеклом, z-fighting, двойная обводка, затемнение или белые клинья у дна). Сравнить дно банки
без hover, с hover и при вращении камеры; все цвета hover (BLUE, WHITE, GREEN, RED) должны работать, смысл состояний не менять.
ВНИМАНИЕ: файлы hover сейчас правит другая сессия (не закоммичено); перед запуском задачи уточнить у заказчика, что делать с теми правками.
Критерий: при hover на любой банке дно подсвечивается ровно, без пятен, клиньев, мерцания и двойных контуров, с любого ракурса.
