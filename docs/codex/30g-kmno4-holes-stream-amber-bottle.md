# Задача для Codex: KMnO₄ — «дырки», струя-стержень, склянка KMnO₄ (30g)

Состояние закоммичено: `5f9554e` (облака KMnO₄ 30f), `39d38a4` (склянки). Принятое не ломать:
облако KMnO₄ с плотной серединой, окраска и тон меди, творожистый AgCl, каустика, уровень/мениск/
горизонт жидкости в склянке и убывание при переливании.

**Экранное преломление склянок из 30f удалено** (`39d38a4`): заказчик увидел, что склянки становятся
розовыми. Захват кадра делался раз за `renderer.render` с размером экрана; при рендере в другие цели
(поднос, планшет — свои камеры/render target) жидкость брала чужую картинку и рисовала её с `alpha = 1`.
Не возвращай экранный захват. Урок: любые общие для кадра ресурсы проверяй при нескольких рендерах
за кадр (поднос, планшет) — снимай и эти виды.

## 1. KMnO₄ в пробирке: белые овальные «дырки»
`tmp/visual/30f/HIGH/kmno4-redox-2s/3s-tube.png` — бледные белые овалы справа на облаке (были и в 30e).
Пузырьки приливания для окрашенной струи ты уже скрыл — значит, источник другой. Найди точно: отключай
по очереди слои (`TubePourWallFilm`, пузырьки, `tracerRidge`, мениск/`capRim`, каустики, блики стекла,
`waveSurface`) на одном и том же кадре, пока овалы не пропадут; опиши в отчёте, что это было, и исправь
причину.

## 2. KMnO₄: струя — стержень по оси
Кадры 0.5–1 с: от горлышка по оси пробирки идёт малиновый вертикальный стержень. Должна быть
**плёнка по внутренней стенке** (как бесцветная в 30d: прижата к стеклу, 2–4 мм, по кривизне,
полупрозрачная, видна по бликам), у KMnO₄ — малиновая, полупрозрачная, ярче у кромок. В воздухе по оси —
ничего.

## 3. Облако KMnO₄ — разделить на клубы
Сейчас — приглушённая лилово-серая масса почти во всю ширину. Нужно: насыщенно-малиновые (не серые)
клубы, 2–4 отдельных языка с прозрачными промежутками, середина языка — самая тёмная. Цвет сверь с
фото раствора KMnO₄.

## 4. Склянка KMnO₄ (янтарная)
`tmp/visual/30f/bottles/HIGH/kmno4-hand-0/30/60.png`: тёмно-фиолетовая только полоса у дна под
этикеткой, а выше этикетки до плеча склянка **светится ярко-оранжевым с жёлтыми бликами**. При
уровне 0.65 раствор доходит до верха этикетки — вся эта часть должна быть почти чёрно-фиолетовой (у
кромки поверхности и на просвет — фиолетовой); выше уровня — обычное янтарное стекло. Проверь, не
перекрывает ли `GlassMaterial` (янтарь, `uDenseLiquid`/`uLiquidLevel` = `0.12 + fill·0.66` в
нормализованных координатах стекла) жидкость — сверь уровень в шейдере стекла с реальным уровнем
жидкости при наклоне (сейчас стекло не знает наклона).
