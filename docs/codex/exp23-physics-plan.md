## 2. Что из серии уже сделано, а что нет
- **Уже есть:** общий несжимаемый решатель с проекцией, инертный трассер (отчёт 50d: масса 1,000000, рост дисперсии,
  охват 48→84 %, энергия течения затухает плавно), локальная R3, три размерных класса, донный слой, ресуспензия,
  отладочные срезы за флагом (`tubeFlowDebug.ts`, `window.__tubeDebugEnabled`).
- **Нет / неверно:** (а) **непрерывного видео** диагностики и трёх ракурсов; (б) низкодиффузионной
  скалярной адвекции (края облака BaSO₄ гладкие); (в) **консервативного переноса полей при росте уровня**
  (уровень не растёт вместе с объёмом); (г) единого оседания для двух опытов на абстрактных частицах с
  отладочным балансом `suspended + aggregates + sediment = formed`; (д) мягких хлопьев AgCl и молочной
  взвеси AgCl; (е) объёмной оптики без собственного белого у поверхности; (ж) удаления/проверки
  остаточного таймерного пути `TubeMixingField` в опытах 2 и 3; (з) свободной поверхности как живой
  части жидкости; (и) видео-сравнение и метрики.

## 3. Порядок исполнения (адаптация порядка заказчика) и причины
Порядок заказчика 52→53→54 → 55 → 58 → 57+60+59 → 56+60+59 → 61+62 **сохранён**. Отличия и причины:
1. **52+53+54 — одно задание (ворота 1):** решатель и транспорт уже есть; нужны проверка отладочным
   режимом, **видео** трассера, низкодиффузионная адвекция и **консервативный перенос при росте уровня**.
   Рост уровня (`h(V)` по геометрии) входит сюда, а не в 59: без него требование задачи 54 «консервативно
   переносить при изменении объёма» невыполнимо (сейчас уровень упирается в 2,5 мл).
2. **55+58 — ворота 2** (локальное образование и оседание на абстрактных частицах), как у заказчика.
3. **57+60+59 — ворота 3** (BaSO₄ + объёмный рендер + поверхность): поверхность в одной связке с рендером,
   потому что белая «крышка» — дефект шейдера опыта 3.
4. **56 — ворота 4** (AgCl): завершение незакрытой 51 на общей физике. **Черновик `tubeSilverField.ts` остаётся
   в рабочей копии как основа, но не принимается и не коммитится**, пока не пройдёт ворота.
5. **61+62 — ворота 5.**
Требование «не ломать опыт 4»: любые изменения `TubeFlowSolver` — **за параметром конфигурации экземпляра**;
по умолчанию поведение для KMnO₄ прежнее (проверка: тесты `tubePermanganateField.test.ts`, кадры опыта 4 до/после
совпадают в допуске).

## 5. Критерии отказа в приёмке (заказчик, 12.10) — применяются на каждых воротах
Не принимать, если: жидкость не переносит трассер за пределы входящей струи; завихрения — только шейдерная
анимация; осадок появляется глобально без локальной реакции; частицы исчезают без учёта массы; AgCl по-прежнему
напоминает звёзды; BaSO₄ выглядит как однородный белый дым; осадок не накапливается на дне; при встряхивании
химическое состояние сбрасывается; внешний вид зависит от ракурса из-за плоских эффектов; выполнены только
typecheck/lint без проверки движения. Статичных скриншотов недостаточно: нужны **непрерывное видео, кадры с
нескольких ракурсов, данные сохранения массы, визуализация скорости и концентрации, сравнение с референсом.**
Обратное тоже верно: работающая физика без приемлемого вида — не завершена. Запрещено подменять результат
упрощением без согласования; если архитектура не позволяет — Codex объясняет техническую причину и
предлагает исправление (мне и заказчику).
Последовательность работ (заказчик): диагностика → физика жидкости → проверка трассера → локальная химия →
перенос мелкой взвеси → агрегация AgCl → оседание и накопление → объёмный BaSO₄ → объёмный AgCl → поверхность
и встряхивание → полный опыт и производительность. Соответствует воротам G1–G5.
