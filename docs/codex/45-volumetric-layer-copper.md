## 1. Общий 3D-слой (новые модули в `lib/`, будут общими для всех опытов)
- `LiquidMask(x,y,z)`: сетка 32×64×32 (LOW 16×32×16) в локальной системе пробирки; стекло (цилиндр +
  полусфера дна) и мениск по мировой гравитации, пересчёт при наклоне; клетки вне жидкости = 0.
- `SpeciesField[id]`: объёмные концентрации растворённых веществ (в этом задании — `Cu2+`), без
  отрицательных значений и NaN.
- `VelocityField`: бездивергентный по построению (`u = rot A` на разнесённой сетке), из вкладов:
  медленный curl-noise (слабые объёмные вихри во все стороны) + восходящий шлейф над источником газа на
  меди (сила ∝ текущему источнику NO). Заложи слоты: плавучесть (46), пузырьки (47), ускорения пробирки.
  Не одинаковая вертикальная скорость по объёму.
- Перенос — конечные объёмы, потоки через грани (upwind/MUSCL с ограничителем), нулевой поток через
  стекло и мениск, ограниченная диффузия. Фиксированный шаг 20–30 Гц + аккумулятор, независимо от FPS.
  Поле **не сбрасывается** при перемещении, наклоне, переносе пробирки.
- GPU: две `THREE.Data3DTexture` (предыдущий/текущий шаг) + интерполяция по доле шага.

## 2. Опыт 1, R1 (раздел 2.3 и 3 ТЗ)
- Учёт вещества ведёт `tubeReactions.ts` (его читает планшет — **игровую логику не менять**):
  ξ = progress·ξmax. На шаге dξ: `Cu −3dξ`, `HNO₃ −8dξ`, `Cu(II) +3dξ`, `NO +2dξ` — заведи эти учётные
  количества в `ReactionState` (условные единицы, отдельно от видимой насыщенности).
- `Cu(II) +3dξ` распределяется в клетки у **смоченной поверхности 3D-гранулы** (позиция и масштаб после
  уменьшения), по нескольким активным микрозонам разной силы, медленно меняющимся (не круг, не сфера).
- `NO +2dξ` в этом задании — только как сила восходящего шлейфа в `VelocityField` (пузырьки и газ —
  задание 47). Существующие пузырьки и газ не трогать.

## 3. Объёмный рендер Cu²⁺ (раздел 8 ТЗ)
- Ray marching по `sampler3D` **только внутри жидкости** (вход/выход луча: цилиндр, дно, мениск),
  остановка по глубине непрозрачных предметов (медь), jitter старта, шагов LOW 16 / HIGH 48.
- Селективное поглощение (Beer–Lambert) по концентрации вдоль луча, умножением, как сейчас; палитра:
  слабо — почти бесцветная холодная голубизна, сильнее — светло-голубой, насыщенно — голубой/сине-
  бирюзовый; итог ≈ эталон `qA7iJcHqiTc` 216–220 с. `emissive = 0`, без дымовых частиц и billboard.
- Убрать аналитическую `copperConcentration` (`tubeAbsorptionMaterial.ts`) из жидкости, прохода
  поглощения и погружённых тел (`tubeImmersion.ts`) — всё читает поле.
- Цвет не выходит за жидкость, нет срезов и прямоугольных границ поля, медь не исчезает, 360° камера.

## 4. Автотесты (Vitest)
Нет отрицательных значений и NaN; перенос без источника сохраняет сумму (± числ. точность); сумма
`Cu(II)` в поле = 3·ξ (в масштабе); при p=1 нет притока; нагрев без реакции не создаёт `Cu(II)`; шаги
1/30, 1/60, 1/144 дают ту же сумму и близкое распределение; вне `LiquidMask` = 0.
