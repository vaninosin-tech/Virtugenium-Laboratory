# Задача для Codex: форма языков KMnO₄ — убрать «леденец» (44)

Состояние: закоммичено (c23eb4a, итерация 43). Цвет (малиново-розовый) и время обесцвечивания
(к ~3 с прозрачно, без крупинок и мути) — **приняты, не менять**. Остальные опыты не трогать.

## Проблема
Кадры `tmp/visual/closeups/c43-final/4-kmno4-0p5s…2s.png`: окраска — **ровные параллельные
диагональные полосы** (как на леденце, видна регулярная структура), и уже на 0.5 с розовым заполнен
почти весь столб одним блоком с прямыми краями.

## Как должно быть
Эталон https://www.youtube.com/watch?v=2q4Fm9v_fHk, кадры `tmp/reference/frames/exp4b-2q-fine/`
(0.25 с на кадр, 37.75–38.75 с), раздел «Опыт 4» в `docs/realism/README.md`:
- струйка входит сверху и даёт **1–3 языка неправильной формы**, которые опускаются, клубятся и
  рвутся на тонкие нити; между ними и вокруг — прозрачная жидкость;
- никакой периодической структуры (полос, спирали с ровным шагом); шум без видимого периода
  (несколько октав, domain-warp), форма — из поля переноса (струя вниз → растекание → завитки);
- языки бледнеют с краёв и исчезают к ~3 с (как сейчас).
