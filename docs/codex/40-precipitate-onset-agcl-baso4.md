## Как должно быть
**Опыт 2** (эталон https://www.youtube.com/watch?v=54x6WkujoyQ, кадры `tmp/reference/frames/exp2-54x-fine/`,
0.5 с на кадр): 0–1 с — белые хлопья **у поверхности**, где вошёл NaCl, ниже жидкость **прозрачная**;
1.5–3 с — плотные белые **ватные комья** (неправильные, с рыхлым краем, не сферы) растут и **падают через
прозрачную жидкость**; 3.5–5 с — рыхлая кучка на дне; 6–9 с — полупрозрачные молочные разводы над ней;
позже медленно — равномерная полупрозрачная молочность. Никакой мгновенной мути по всему столбу, никаких
вертикальных полос.

**Опыт 3** (эталон https://www.youtube.com/watch?v=KpPvVc8nV70, кадры `tmp/reference/frames/exp3-Kp-fine/`,
0.25 с на кадр, время видео 4–10 с): от места входа K₂SO₄ — маленькое белое **дымчатое облако** с
волокнистыми краями; облака **опускаются и клубятся**, выше прозрачно; за ~3 с низ заполнен плотными
клубами, вверху завитки; затем весь объём — **равномерное непрозрачное молоко** (как сейчас). Мягкий
«дым», не комья. Оседание дальше — как сейчас (принято).

Модель переноса (`tubeMixingField`) и проход поглощения/рассеяния уже есть — используй их для облаков
(концентрация осадка в поле → непрозрачность/белизна), а не равномерную муть по прогрессу.
