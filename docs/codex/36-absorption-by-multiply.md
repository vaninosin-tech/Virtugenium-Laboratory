# Задача для Codex: окрашенные растворы фильтруют фон (умножение), а не заливают его (36)

Почему: три итерации подряд (медь 32, KMnO₄ 35, ранее BaSO₄) «плотнее» давало «серее». Окрашенный раствор
сейчас рисуется alpha-over: `dst = mix(dst, liquidColor, alpha)`. Тёмный цвет поверх светлого фона —
это серый, насыщенности так не получить. В жизни раствор **фильтрует** свет: `dst = dst · T`, где
`T = exp(-σ · c · L)` по каналам (Бугер–Ламберт), L — длина пути луча в жидкости, c — концентрация.
Это даёт насыщенный синий у меди на белом фоне и почти чёрный фиолетовый в толще KMnO₄ с малиновым
тонким слоем — как на эталонах (`docs/realism/README.md`, листы `tmp/reference/sheet-exp1dil-*`,
`sheet-exp4-*`). Твоя неудачная попытка 35 сохранена в `tmp/codex/35-attempt.patch` (не применять).

## Что сделать
1. Для окрашенных растворов (медь — `copper-nitric`; KMnO₄ — `permanganate-redox` и сама склянка/
   пробирка с KMnO₄) — **отдельный проход поглощения**: меш по геометрии жидкости (стенка + крышка
   поверхности) с `THREE.CustomBlending`, `blendEquation = AddEquation`, `blendSrc = ZeroFactor`,
   `blendDst = SrcColorFactor` (то есть `dst · src`), `depthWrite = false`, выводит `T` (без тонмаппинга,
   `toneMapped = false`). L — аналитически по лучу через цилиндр пробирки и плоскость поверхности (как в
   `transmitThroughTube` в `tubeReactionVisuals.ts`), c — из уже существующих полей (медь: `localMix`/
   прогресс; KMnO₄: поле красителя `uTransport`, облака).
   - σ меди (Cu²⁺ aq): сильно поглощает красный, умеренно зелёный, слабо синий → сине-голубой;
     промежуточная бирюза (эталон exp1dil 132–148 с) — по ходу реакции.
   - σ KMnO₄: очень сильно зелёный, умеренно красный и синий → тонкий слой малиново-пурпурный,
     толща — почти чёрная фиолетовая.
   - Порядок отрисовки: после непрозрачной сцены и задней стенки стекла, до передней стенки стекла и
     бликов. Проверь, что проход не красит ничего вне жидкости и не ломает пузырьки/медь
     (`tubeImmersion` — тон предметов сохранить согласованным с новым σ).
2. Существующий alpha-over материал жидкости оставить только для бликов, мениска, ряби, мути —
   **с малой непрозрачностью**, чтобы не сероватить. Белая муть (AgCl, BaSO₄) — рассеяние в белый
   (как сейчас у BaSO₄: непрозрачное «молоко»), не умножение.
3. **AgCl (опыт 2)**: сразу после приливания весь столб — плотная молочно-белая творожистая муть
   (эталон `exp2-Fz8zYQW4Ts4` 36–38 с), как у BaSO₄ в `8439158`, но с видимыми рыхлыми хлопьями; затем
   медленное створаживание и оседание.
4. Склянки (`reagentMaterials.ts`): KMnO₄ в янтарной склянке — тоже через умножение, если это не
   ломает принятый вид; иначе не трогай.
