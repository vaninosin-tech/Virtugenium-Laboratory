# Задача для Codex: облака KMnO₄ без «блока», преломление в склянках (30f)

Состояние: закоммичено `1239a4b`. Из 30e принято: жидкость в склянках (уровень, мениск, горизонт при
наклоне, тёмно-фиолетовый KMnO₄ в склянке), насыщеннее раствор меди. **KMnO₄ в пробирке откачен к виду
30d** — попытка 30e сохранена целиком в `tmp/codex/30e-tube-attempt.patch` (не применяй её как есть).

Я исправил твою ошибку в `BottleLiquidMaterial`: в вершинном шейдере было
`vec3(position.xz, y)` — это (x, z, y), цилиндр жидкости ложился на бок и выходил из склянки (заказчик
увидел это в игре). Теперь `vec3(position.x, y, position.z)`. Учти урок: такие ошибки видны только на
крупном кадре — снимай склянки крупно (см. «Проверка»).

## 1. KMnO₄ в пробирке — облака с плотной серединой, без артефактов
В 30d: мягкие языки, но **пустая середина** (контур). В 30e причина найдена верно — центральный луч
повторно читал один столбец поля; выборка по повёрнутому срезу это чинит. Но в 30e получилось хуже:
`tmp/visual/30e/HIGH-review/kmno4-redox-0p75s…1p5s-tube.png`:
- **сплошной розовый блок** во всю ширину с резкой горизонтальной верхней границей — коэффициенты
  поглощения (×12, ×4.3, `pow(…, 0.78)`, альфа `raspberry² · 0.72`) задраны так, что любой след
  красителя даёт полную заливку;
- **белые овальные «дырки»** справа на блоке (артефакт — найди источник: пузырьки воздуха приливания
  поверх, блик, выборка вне поля?);
- струя — **толстый сплошной стержень** по оси пробирки, а не плёнка по стенке (плёнку из 30d не терять).
Возьми из патча 30e только исправление выборки (поворот среза в глубину), коэффициенты подбирай заново
по кадрам: середина клуба тёмно-малиновая, к краю мягко сходит на нет, между клубами — прозрачные
промежутки, верхней горизонтальной границы нет. Обесцвечивание к 5–8 с. Струя — как в 30d (плёнка).

## 2. Склянки — преломление и вид при наклоне
Сейчас уровень и мениск видны (`tmp/visual/30e/HIGH-bottles-axisfix/*.png`), но:
- **этикетка и фон сквозь жидкость не искажаются.** У настоящей склянки ниже уровня то, что за ней,
  видно растянутым по горизонтали (цилиндрическая линза), а сама задняя половина этикетки — через
  жидкость. Встроенное преломление three.js у тебя не дало эффекта — вероятно, оно не видит прозрачные
  объекты/этикетку. Сделай дешёвое экранное смещение: один общий на кадр захват непрозрачной сцены
  (или переиспользуй существующий из пробирки, итерации 22–22c), смещение UV по нормали жидкости и
  толщине; на LOW — без захвата (лёгкое затемнение/сдвиг блика). Без отдельного прохода на склянку.
- **не сняты склянки в руке при наклоне 0°/30°/60°** — сними: поверхность горизонтальна в мире, жидкость
  не выходит за стекло, объём сохраняется, при переливании уровень падает.
- **бесцветная склянка:** чуть больше различимости объёма ниже уровня (лёгкая голубизна по краю,
  тёмная линия под мениском), но без мутности.
