# Задача для Codex: после исчезновения гранулы пузырьков нет

Короткая доводка после итерации 15. Заказчик спросил, должны ли пузырьки оставаться после
исчезновения гранулы. Нет: NO рождается только на поверхности меди, пока идёт реакция.

Сейчас вживую после полного растворения гранулы (progress = 1) в жидкости всё ещё висят/поднимаются
отдельные пузырьки, как будто реакция продолжается.

Нужно:
- когда гранула исчезла (или rate = 0), **новые пузырьки не рождаются вообще**;
- уже летящие/прилипшие — всплывают и исчезают за 1–2 с;
- допускается пара крошечных пузырьков, прилипших к стеклу у дна, которые остаются неподвижно
  (как в реальности) — но не поток и не всплывающие пузыри;
- то же при остывании: пузыри затухают вместе с rate, без «вечной» минимальной струйки.

Только это. Разрешено: `tubeReactionVisuals.ts`, `tests/visual/*`, `tests/tubeReactionVisuals.test.ts`.
Снимки в `tmp/visual/16/`: конец реакции, +1 с, +3 с, +10 с, HIGH и LOW. Без commit/push. В конце —
typecheck, vitest, build, короткий отчёт по-русски с путями.
