# Задача для Codex: осадок BaSO₄, редкие крупные частицы, старт реакции (50e)

Обязательные документы: `docs/codex/50c-baso4-onset-settling.md` (разделы 3, 8, 9, 10, 14, 15 — основа
этого задания; все его замечания заказчика действуют), `docs/realism/game-rules-amounts.md`,
`docs/realism/local-reaction-onset.md`. База — закоммиченные 45–50d (aad82d8): `lib/tubeBariumField.ts`,
`lib/tubeBariumSediment.ts`, `lib/tubeFlowSolver.ts`, `lib/tubeReactionVisuals.ts`, `tubeSimulationConfig.ts`.
Принятое не ломать: локальное начало реакции, общий решатель течения, оседание по размерам с переносом
массы, баланс масс, прогресс для планшета, опыты 1, 2, 4.

## Что не так (мои кадры по actual, `SCREEN=1`, и крупные планы — `tmp/visual/50c-delivery/`)
1. **Донный осадок — главный недочёт (50c п.8–9).** Нужен плотный мелкозернистый слой реальной
   толщины, заполняющий нижнюю часть закруглённого дна, с чуть неровной поверхностью, не шарики, не
   декаль; растёт с массой. Сейчас на боковом крупном плане это небольшая округлая «миска» **тёплого
   оранжево-кремового цвета** (не белая), спереди на 60 с осадка не видно. Проверь: цвет (материал
   осадка в `tubeReactionVisuals.ts` — `uSedimentWhite`/освещение/порядок прозрачного рендера), высоту
   слоя от массы `SedimentField`, геометрию по форме дна (полусфера + цилиндр), мелкозернистую
   неровность поверхности (шум по нормали/высоте, не по цвету), видимость сквозь стекло и жидкость
   с любого ракурса (front, side, top, 45°).
2. **Редкие крупные частицы/агрегаты (50c п.3).** Сейчас их нет. Добавить **редкие** небольшие объекты
   (instancing, пул), рождаются из мелкой взвеси при локально высокой концентрации, **редкие
   по отношению к общей массе**, разного размера, неправильной формы (не одинаковые сферы, не
   творожистые хлопья AgCl), увлекаются потоком, оседают быстрее мелкой взвеси, попадают в
   `SedimentField` с сохранением массы. Масса: взвесь + крупные + осадок = образовано (тест).
3. **Помутнение (50c п.2).** Допустимо почти непрозрачно к 1–3 с при достаточном количестве; сейчас на
   3 с ~половина (progress 0,52). Не за счёт включения белого на всём объёме — за счёт скорости R3 и
   перемешивания (сохранить локальное начало); цель — молочный столб к ~3–5 с.
4. **Левая/правая стенка в штатном ракурсе почти неразличимы** (отчёт 50d). Пристеночное попадание
   должно давать заметно иную картину, чем центральное: проверь, что точка входа реально смещается
   (`tubePourImpact`/`inlet`), что решатель прижимает струю к стенке (граничные условия), и снимай
   варианты с двух ракурсов (front **и side**, чтобы разность была видна).
5. **Встряхивание (50c п.10) — показать на кадрах.** Создай тестовый вызов (в песочнице/скрипте, за
   флагом), который прикладывает к пробирке реальные ускорения/повороты (через `tubeMotion`), и сними
   серию: слабое движение — слой на месте; сильное — часть осадка поднимается, у дна локальная муть,
   затем снова оседает; масса сохраняется (цифры). Не создавать новый BaSO₄.
6. **Заморозка при старте реакции в опытах 1 и 2** (~10–13 с до первого кадра; для 3 и 4 уже есть
   `prewarmBariumLiquidShader`). Сделать предкомпиляцию шейдеров/материалов для опытов 1 и 2 аналогично
   (до налива последнего реагента; по `compileAsync`/прогреву), не пересоздавая материалы в момент
   налива. Замер: максимальная пауза кадра после начала реакции < 100 мс для всех четырёх опытов.
7. **Видео (50c п.14).** Реальное по времени: собрать из кадров `SCREEN=1` по `actual` (ffmpeg из
   imageio-ffmpeg, 24 к/с с повторением кадров по меткам времени) — не запись во время работы, которая
   замедляет игру. Сюжет: попадание струи, облака, молочный столб, оседание, донный слой, встряхивание.

## Приёмка
- Кадры по `actual`: 0; 0,1; 0,25; 0,5; 1; 2; 3; 10; 20; 30; 45; 60 с (front и side) + крупный план дна
  на 30 и 60 с — **осадок белый, плотный, по форме дна, с реальной толщиной**; видно крупные частицы.
- Тесты: баланс `suspension + coarse + sediment = образовано`; высота слоя растёт с массой; встряхивание
  возвращает часть массы во взвесь; нет NaN; крупных частиц мало по массе (доля задана параметром).
- Регрессии: опыты 1, 2, 4, полный Vitest, FPS в LOW, пауза после налива.
