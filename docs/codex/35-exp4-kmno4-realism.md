## Что видно на эталоне
- 34–43 с: раствор KMnO₄ в пробирке — **почти чёрный фиолетовый** в толще, малиново-пурпурный только в
  тонком слое (капли на стенке, кромка мениска).
- 44–57 с: после добавления второго реактива — **плавный градиент**: сверху светлеет до розово-малинового
  и затем бесцветного, внизу долго тёмно-фиолетовый; граница мягкая, без полос.
- В видео порядок обратный нашему (KMnO₄ налит первым). У нас KMnO₄ приливают в подкисленный сульфит —
  поэтому вид другой по форме, но **те же цвета и та же логика**: плотный KMnO₄ — тёмно-фиолетовый,
  разбавляясь и реагируя — проходит малиновый → розовый → бесцветный.

## Сейчас в игре (сравнение `tmp/visual/compare/exp4.jpg` по кадрам 30g)
Клубы — **светло-малиновые**, нигде нет тёмно-фиолетовой плотности; обесцвечиваются, просто бледнея.

## Что сделать
1. Цвет по плотности (Бугер–Ламберт по каналам, а не одна «малиновая» краска): тонкий слой — малиново-
   пурпурный, толща/ядро клуба — **тёмно-фиолетовый до почти чёрного**; края — розовеют.
2. Обесцвечивание идёт через **малиновый → розовый → бесцветный**: первыми теряют цвет края клубов в
   контакте с раствором, ядро держится дольше; без «выцветания всего сразу». Длительность — по химии
   (`seconds`), не растягивать сверх неё; если для заметности нужен запас — опиши в отчёте, не меняй химию.
3. Струя KMnO₄ по стенке (30g) — того же цвета по толщине (тонкая — малиновая).
4. Склянка KMnO₄ уже тёмная (30g) — сверь, что струя и склянка одного вещества по цвету.
