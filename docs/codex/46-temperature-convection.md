# Задача для Codex: TemperatureField и конвекция (46)

Главное ТЗ — `docs/realism/chemistry_four_experiments_corrected.md` (разделы 2.1, 3 п.5, 7, 9 тест 3). План — `docs/codex/cu-hno3-plan.md`.
База — 3D-слой из задания 45 (закоммичен).

## Что сделать
- **TemperatureField** на сетке 3D-слоя (можно грубее, напр. 16×32×16): приток тепла от пламени в месте
  контакта со стеклом — из `useHeatingStore` (`sweep`, `bottomInFlame`, `active`, цель нагрева) и
  `useBurnerStore.lit`; теплопроводность в жидкости, инерция, остывание через стекло. Сторона нагрева и
  смещение пламени меняют зону притока. Нагрев не моментальный.
- Средняя температура поля питает существующий `chemistry.temperature` (скорость R1) — **одна истина**,
  без двух несвязанных температур. Калибровка средней температуры — как сейчас (нагрев ~12 с,
  остывание ~40 с в `tubeReactions.ts`).
- **Плавучесть → VelocityField**: вклад в векторный потенциал от горизонтальных градиентов температуры
  (тёплое вверх по мировой гравитации, компенсационные нисходящие потоки у холодных стенок), асимметрия
  по положению пламени. Остаточная конвекция затухает плавно после снятия с огня; повторный нагрев снова
  усиливает.
- **Движение пробирки**: гравитация в локальной системе при наклоне; ускорение при переносе/встряхивании
  даёт временный вклад в поток. Поля не сбрасываются.
- Раздельные законы для опытов (раздел 7 ТЗ): общий `temperatureMultiplier` на всё — запрещён.
- Нагрев без реакции **не создаёт** продуктов.

## Проверка
Опыт 1: холодно → нагрев → снять с огня → снова нагрев (песочница/скрипт); кадры вблизи с ракурсов:
струи Cu²⁺ ускоряются, меняют направление, затухают плавно. Автотесты: тепло без реагентов не создаёт
Cu(II); баланс сохраняется; конвекция затухает не мгновенно; 30/60/144 FPS — сопоставимо.

Окружение: только модель по умолчанию; чужие незакоммиченные файлы не трогай (`ui/`, `sandbox/` — мои незакоммиченные правки: использовать можно, менять нельзя); один браузер; Vitest `npx vitest run --no-file-parallelism tests src`. Разрешено: `tube*.ts` и общий 3D-слой в `lib/` (из задания 45), `tubeReactions.ts` (не меняя `progress`/`rate`, которые читает планшет, кроме случаев, прямо описанных в задании), новые файлы в `lib/`, тесты, `tests/snap-closeups.mjs`.
