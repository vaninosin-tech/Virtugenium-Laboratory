# Задача для Codex: 3D-поле Cu²⁺ и объёмный рендер (45)

Общий план — `docs/codex/cu-hno3-plan.md` (прочитай целиком, особенно «Решение — полностью 3D»).
Первое из четырёх заданий по ТЗ заказчика Cu + HNO₃. Состояние: закоммичено (2f9e728). Опыты 2–4,
пламя, струя из склянки, газ — не трогать. Прошлая попытка на 2D-срезе (`tmp/codex/45-attempt.patch`)
**отклонена** — заказчик требует настоящее 3D; патч не применять.

## Суть
Сейчас голубизна — аналитическая функция `copperConcentration(...)` в GLSL
(`lib/tubeAbsorptionMaterial.ts`, используется жидкостью, проходом поглощения и `tubeImmersion.ts`):
облако + одна струя по прогрессу и времени, в конце `mix(partial, 1.0, homogeneous)` — «цвет по
таймеру». Нужно **трёхмерное скалярное поле концентрации Cu²⁺**, которое рождается у меди,
переносится жидкостью и рисуется объёмно.

## 1. Поле (новый модуль в `lib/`, например `copperIonField.ts`)
- Сетка 32×32×64 (LOW 16×16×32) в **локальной системе пробирки**; маска жидкости: цилиндр радиуса
  стекла + полусфера дна + свободная поверхность (уровень по гравитации — уже считается для жидкости).
- **Источник**: клетки у смоченной поверхности 3D-гранул меди (`TubeCopperGranules`, их позиции и
  масштаб после уменьшения), неравномерно по поверхности (несколько активных участков с разной
  силой, медленно меняющихся), суммарный приток ∝ d(progress)/dt. Без реакции и при p=1 — ноль.
- **Скорость** бездивергентная по построению: `u = rot A` на разнесённой сетке. В этом задании A =
  curl-noise с медленной эволюцией (слабые объёмные вихри во все стороны) + восходящий шлейф над
  медью, сила которого растёт с `rate` (пузырьки) — заложи слот, куда 46 добавит плавучесть, а 47 —
  пузырьки. Не одинаковая вертикальная скорость по всей жидкости.
- **Перенос**: конечные объёмы, потоки через грани (upwind или MUSCL с ограничителем), нулевой поток
  через стекло и поверхность; **диффузия**. Фиксированный шаг (20–30 Гц) с аккумулятором; поле не
  выключается по таймеру.
- **Выгрузка**: две `THREE.Data3DTexture` (предыдущий/текущий шаг, R8 или R16F), в шейдере —
  интерполяция по доле шага, чтобы потоки не дёргались.

## 2. Объёмный рендер
- Ray marching по `sampler3D` **внутри жидкости**: вход/выход луча по цилиндру, дну и плоскости
  поверхности; trilinear-сэмплинг, jitter старта (без полос), шагов LOW 16 / HIGH 48.
- **Глубина непрозрачных предметов**: луч останавливается на меди (нужна глубина сцены — depth-проход
  или `DepthTexture`), медь не пропадает и окрашивается тем, что перед ней.
- Оптика — поглощение по Beer–Lambert вдоль луча (как сейчас, умножением), палитра §6.1 ТЗ: слабая →
  почти бесцветная холодная голубизна, средняя → светло-голубая, высокая → насыщенная голубая /
  сине-бирюзовая; конец ≈ эталон `qA7iJcHqiTc` 216–220 с. Не emissive, не непрозрачно.
- Цвет **не выходит за жидкость**, нет прямоугольных границ и срезов поля, нет billboard и плоских
  текстур. Аналитическую `copperConcentration` убрать из жидкости, поглощения и погружённых тел.

## 3. Стадии (§12 ТЗ) — из поля, не по таймеру
0–10% — едва голубое у меди; 10–25% — локальные облака; 25–45% — **различимые полупрозрачные
объёмные шлейфы**; 45–70% — шлейфы по большей части объёма; 70–90% — почти всё, градиенты видны;
90–100% — выравнивание перемешиванием.

## 4. Тесты (Vitest)
Масса сохраняется при переносе без источника; при p=1 нет притока; шаги 1/30, 1/60, 1/144 дают ту же
массу и близкое распределение; без реакции поле пустое; концентрация вне маски жидкости = 0.
