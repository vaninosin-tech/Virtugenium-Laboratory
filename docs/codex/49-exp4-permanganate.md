# Задача для Codex: опыт 4 — MnO₄⁻ + SO₃²⁻ в кислой среде, R4 (49)

Главное ТЗ — `docs/realism/chemistry_four_experiments_corrected.md` (разделы 0 опыт 4, 1, 2.3 R4, 6, 7, 8, тесты 6–8, 12). База — общий 3D-слой
(45–48, закоммичены). Прошлые решения (языки по таймеру, канал `dyed` в `TubeMixingField`,
«обесцвечено к 3 с») заменить.

## Что сделать
- `SpeciesField`: **MnO₄⁻**, **SO₃²⁻**, **H⁺** (учётно SO₄²⁻, Mn²⁺). Подкисленный сульфит уже заполняет
  раствор; MnO₄⁻ входит **струёй из склянки** в реальной точке входа (`PourStream`), с импульсом.
- **R4 локально в каждой клетке**: ξ ограничен доступными количествами; расход строго
  `MnO₄⁻ : SO₃²⁻ : H⁺ = 2 : 5 : 6`, продукты `SO₄²⁻ +5ξ`, `Mn²⁺ +2ξ`. Цвет — **только оставшийся MnO₄⁻**
  (Beer–Lambert; розовый → малиново-фиолетовый, не чёрный). Края языков гаснут первыми.
- Направление языков — от импульса, относительной плотности (параметр), ориентации и течения, **не
  «всегда вниз»**.
- Избыток MnO₄⁻ → раствор остаётся розовым/фиолетовым. Никаких частиц, мути, MnO₂. SO₂ — выключен.
- Игровая логика: `progress`/`rate` для планшета (`useStageSceneState`) вывести из учёта R4 (ξ/ξmax),
  этапы планшета должны работать как раньше — проверь.
