# Задача для Codex: пузырьки NO и газовая фаза NO/NO₂ (47)

Главное ТЗ — `docs/realism/chemistry_four_experiments_corrected.md` (разделы 0, 2.1 GasState, 2.3 R1, 3 п.2 и п.7, «Важное о пузырьках», 8, тесты 1–2,
11). База — 45–46 (закоммичены).

## Пузырьки NO (бесцветные)
- Источник — учётное `NO +2dξ` из R1. Зарождение на **смоченной поверхности 3D-гранулы** в
  стохастических микрозонах; частота ∝ источнику NO и площади (видимые меши — выборка общего потока, не
  «N в секунду из уравнения»); аккумулятор по времени, не по кадрам.
- Цикл: зарождение → прикрепление и рост → отрыв → подъём против мировой гравитации со скоростью по
  радиусу + увлечение `VelocityField` → исчезновение у мениска со слабым возмущением. Не сквозь стекло.
- Размеры разные (большинство мелкие), без регулярных цепочек. Instancing + пул, без аллокаций в кадре.
- Пузырьки дают вклад в `VelocityField` (локальный подъём) — струи Cu²⁺ изгибаются за ними.
- Бесцветные: никаких бурых пузырьков.

## GasState: NO и NO₂ раздельно
- NO из пузырьков поступает в газовое пространство над мениском (бесцветен).
- Отдельная реакция `2NO + O₂ → 2NO₂` по η, **только при доступности O₂** — параметр (по умолчанию
  открытая пробирка, O₂ есть; переключатель в настройках разработчика для теста «без O₂»).
- Бурый — только от NO₂, только **над мениском** / у горлышка, развивается **после** появления NO.
  Заменить нынешний бурый фронт по таймеру от начала нагрева (`airBrownAge` в `tubeReactionVisuals.ts`).
- Экономичный объёмный рендер газа (существующий headspace-шейдер можно перевести на плотность NO₂).

## Проверка
Тест 1 (без O₂): пузырьки NO, голубой Cu²⁺, бурого нет. Тест 2 (с O₂): бурый только в газе над мениском и
после NO. Кадры вблизи с ракурсов, холодно и при нагреве. Автотесты: число пузырьков не зависит от FPS;
баланс NO (образовано = в газе + перешло в NO₂); нет пузырьков без реакции.
