## 1. Зарождение (55 + дополнение §1)
Локальная модель по **пересыщению**: `S = (a₊·a₋)/Ksp` (в учебных нормированных единицах; параметры растворимости в
конфиге по веществу, не реальные числа), скорость зарождения первичных частиц растёт с `S` выше порога,
расход растворённых ионов строго 1:1, рост существующих частиц. Без искусственной задержки. Разные концентрации
→ разный результат (число/размер/масса). Двухцветная диагностика: ион A (напр. красный), ион B (синий) и
источник продукта (белый) — источники совпадают с зоной смешивания, вне контакта продукта нет; избыток или
недостаток реагента меняет итоговую массу (BaSO₄ +10 %, AgCl +15 % по `game-rules-amounts`).

## 2. Классы размеров и фазы
Классы: первичные, мелкая взвесь, небольшие агрегаты, крупные агрегаты (для AgCl; для BaSO₄ минимум), донный
слой. Для каждого — эффективные размер, плотность, пористость, сопротивление, скорость оседания, вероятность
агрегации, оптическое рассеяние (параметры в конфиге). Мелкое — объёмные поля (3D), крупные видимые — объекты.
Переходы между классами — **только перераспределением массы** (тест: нет удвоения).

## 3. Оседание (58 + §6–7, 12)
Скорость частицы = скорость жидкости + собственная скорость оседания по размеру/эффективной плотности/
сопротивлению (Стокс там, где применим; замедление в плотной взвеси — hindered settling); **направление —
мировая гравитация** (не ось пробирки при наклоне); не через стекло и осадок. Малое обратное влияние твёрдой
фазы на жидкость (плотность смеси) — только при высокой концентрации, параметром. Ускорение позднего оседания
×4 (BaSO₄) / ×3 (AgCl) — только при спокойной жидкости, как в `game-rules-amounts`.

## 4. Донный осадок (58 + §8–9)
Поле массы на поверхности дна (по геометрии: полусфера + цилиндр, **с учётом наклона внутренней поверхности**),
распределение по месту контакта, перемещение вещества по поверхности вниз (осыпание), накопление, **высота
слоя из массы и пористости**, а не отдельный рост меша; неровность; уплотнение со временем **с сохранением
массы** (меняются пористость и высота); повторное взвешивание — только при достаточном придонном сдвиге/
ускорении, частично, сначала локальная муть у дна, затем перенос общим `u` (не одним событием).

## 5. Численная корректность и испытания (13, 15)
Баланс `totalProduct = suspended(по классам) + aggregates + sediment`, остатки реагентов, `massBalanceError`;
нет отрицательных; нет потерь на границах; перенос при росте уровня; независимость от FPS; два разрешения
сетки (качественно и по балансу совпадают). Испытания A–I из дополнения (A: разная скорость налива; B: разные
точки; C: конец налива; D: покой; E: перемещение; F: повторное взвешивание; G: два разрешения; H: пауза/
продолжение; I: частоты кадров) — те, что применимы без AgCl-визуала; результаты — таблицей.

## Приёмка ворот 2

диагностика); мелкая взвесь убывает **из-за оседания**, масса переходит в донный слой (графики/числа во
