## Количества (game-rules-amounts §1–2)
В пробирке 2,5 мл AgNO₃; полная добавка NaCl — 1,0 мл; **Ag⁺ на ~15 % больше**, чем Cl⁻ полной добавки.
Налив по клику — фиксированная порция 1,0 мл. AgCl = количество прореагировавших ионов.

## Что сделать
- Поля **Ag⁺** (в растворе) и **Cl⁻** (входит через канал попадания струи 50b, с импульсом ∝ расходу).
  **R2 локально**: `Ag⁺ −ξ`, `Cl⁻ −ξ`, `AgCl(s) +ξ` только где оба есть → мелкая взвесь
  (**SuspensionField**, своя кривая оседания, не как у BaSO₄). В других областях реакция начинается
  только после прихода туда Cl⁻.
- Часть мелкой массы агрегирует в **FlocAggregate[]**: центр масс, масса, неправильная форма, пористость,
  скорость; слияние **суммирует массы**. Форма — неправильные рыхлые лобы/изоповерхности с пустотами и
  хвостами, работает с любого ракурса; **не сферы, не гроздья шариков, не billboard**. Instancing/пул.
  Агрегация — вероятностная, от локальной концентрации и сдвига течения; **нагрев не задаёт её
  коэффициентом** (§7: только через течение/вязкость, если вообще).
- Оседание по размеру, плотности и сопротивлению; увлечение потоком; не сквозь стекло.
  **SedimentField**: рыхлый неровный пористый слой — рыхлее и выше, чем у BaSO₄.
- **Встряхивание** (общий механизм 50b): хлопья поднимаются и частично разделяются (масса сохраняется),
  часть донного слоя — во взвесь; затем повторное оседание.
- **Ускорение позднего оседания** при спокойной жидкости — до ×3 (§5), плавный возврат к ×1.
- Оптика — рассеяние; молочность взвеси по оптической толщине; хлопья — непрозрачные белые объёмы.
- `progress`/`rate` для планшета — из учёта R2 (доля израсходованного Cl⁻ полной добавки), со страховкой
  (поле не обновлялось >1 с — простая кинетика). Этапы планшета не ломать.

## Эталон вида (принятый ранее, видео https://www.youtube.com/watch?v=54x6WkujoyQ, кадры
`tmp/reference/frames/exp2-54x-fine/`, 0,5 с на кадр)
0–1 с — белые хлопья у места входа, ниже прозрачно; 1,5–3 с — ватные комья растут и падают через
прозрачную жидкость; 3,5–5 с — рыхлая кучка на дне; 6–9 с — полупрозрачные молочные разводы; далее —
медленное осветление. Сравнивать только с реально просмотренными кадрами.

## Приёмка
- Химия (тесты): масса `fine + floc + sediment` = образованному AgCl; при слиянии и разделении масса
  сохраняется; Ag⁺ в остатке ≈ 15 % после полной добавки; нет отрицательных/NaN; без контакта нет реакции.
- 3D: песочница — попадание слева/в центре/справа, медленно/быстро; кадры 0,25…3 с, 5, 8,
  12 с и поздняя стадия, front и side; встряхивание переносом пробирки.
- **В обычном прохождении**: налив NaCl из склянки (автопозиционирование как раньше) в пробирку с AgNO₃.
- **Регрессии**: полный Vitest + прогон управления предметами (взять склянку, налить, вернуть, перенести
  пробирку); регрессия опытов 1, 3, 4.
