# Задача для Codex: опыт 3 — BaSO₄, взвесь и оседание (50)

Главное ТЗ — `docs/realism/chemistry_four_experiments_corrected.md` (разделы 0 опыт 3, 1, 2.1, 2.3 R3, 5, 7, 8, тесты 5, 9–12). База — общий 3D-слой
(45–49, закоммичены). Прошлые решения (облака и оседание по `pourAge`-таймерам, `precipitate: "barium"`
в `TubeMixingField`) заменить.

## Что сделать
- Поля **Ba²⁺** (в растворе) и **SO₄²⁻** (входит струёй в реальной точке входа). **R3 локально**:
  `Ba²⁺ −ξ`, `SO₄²⁻ −ξ`, `BaSO₄(s) +ξ` в зоне смешения → **SuspensionField** (массовая плотность мелких
  частиц с распределением по размерам — преимущественно мелкие; агрегацию не запрещать, а свести к
  минимуму в этом пресете).
- Взвесь переносится потоком; **оседание по размеру** (своё, не как у AgCl): осветление сверху вниз
  следует за `SuspensionField`, не за таймером. **SedimentField(x,z)**: плотный тонкий мелкозернистый
  слой. Встряхивание поднимает часть слоя во взвесь.
- Оптика — рассеяние, молочность по оптической толщине вдоль луча; белое внутри жидкости, не на стекле.
- «Вся пробирка белая за 3 с» — только как демонстрационный пресет.
- Игровая логика: `progress`/`rate` для планшета — из учёта R3, этапы планшета не ломать.

## Проверка
Кадры вблизи по 0.25 с первые 3 с, далее 5, 8, 12 с и поздняя стадия; ракурсы; встряхивание. Эталоны
(`tmp/reference/frames/exp3-Kp-fine/`, `exp3-EZ-fine/`) — только реально просмотренные. Автотесты: масса
`suspension + sediment` = образованному BaSO₄; нет отрицательных/NaN; без контакта нет реакции.
