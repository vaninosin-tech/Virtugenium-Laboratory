# Планшет Virtugenium — автономный стенд

Изолированная копия фичи `features/tablet` из основного проекта
`virtugenium-lab`, со всеми файлами, от которых она зависит (типы
лаборатории, реагенты, данные экспериментов, стор лаборатории, стор
настроек). Ничего из 3D-сцены и остального проекта сюда не входит —
только то, что нужно, чтобы планшет запускался и работал сам по себе.

## Запуск

```bash
npm install
npm run dev
```

Откроется чёрный экран (заглушка вместо 3D-сцены лаборатории) с
планшетом поверх — сначала в свёрнутом виде (виджет в левом верхнем
углу), клик по нему открывает развёрнутую панель со всеми вкладками
(«Опыты», «Этапы», «Теория», «Ошибки», «Ответ», «Настройки»).

При старте в `src/App.tsx` автоматически выбирается опыт
`experiment-copper-nitric-acid` и его первый шаг — чтобы в планшете сразу
было что показывать, а не пустое состояние «выберите опыт».

## Структура

```
src/
  App.tsx                  — демо-обвязка (чёрный фон + инициализация стора)
  main.tsx                 — точка входа
  features/tablet/         — сам планшет (UI + логика)
  entities/laboratory/     — типы лабораторных сущностей, реагенты
  entities/equation/       — типы и валидация химических уравнений
  data/content/experiments.ts — контент: 4 опыта из ТЗ
  stores/laboratory/       — zustand-стор состояния лаборатории
  shared/lib/useSettingsStore.ts — стор настроек (громкость/mute)
```

Пути импортов внутри `features/tablet` не менялись — это те же файлы,
что и в основном репозитории, просто с той же относительной структурой
папок вокруг них. Поэтому доработки отсюда переносятся обратно в
`virtugenium-lab/src` копированием файлов один в один.

## Что не входит

3D-сцена, остальные фичи (`main-menu`, реагентный шкаф и т.д.), Tauri-
обвязка, шрифты `@fontsource` кроме тех двух, что реально использует
планшет (`ibm-plex-sans`, `jetbrains-mono`).
